## Подготовка результатов

После реализации всех модулей выполните:

```bash
python diagnostics.py --output-dir artifacts
```

Скрипт использует вашу реализацию и автоматически создаёт:

| файл | содержание |
|---|---|
| `artifacts/yarn_frequencies.png` | частоты RoPE и YaRN |
| `artifacts/metrics.json` | численные результаты YaRN, MLA и MoE |

Таблицы ниже также заполняются этим скриптом. Строить дополнительные графики и
писать код для обработки результатов не нужно. Не изменяйте содержимое блоков
`GENERATED`: повторный запуск диагностики перезапишет его. Кроме вывода matrix
absorption, каждый ответ должен занимать не более 3–5 предложений. Если вводите
формулу, оформляйте её блоком `$$ ... $$`.

Перед сдачей заполните имя и все поля для ответов.
